Usage

            
Select a PDF, then use the presenter view for the current slide, next slide, notes, and timer.

            
Click on the timer to set the target duration.
            If no target duration is set, the timer counts up when advancing to the next slide for the first time.
            Otherwise, it shows the remaining time. A blue timer means you are too fast, an orange one that you are too slow.
            


            
Use Open Audience Window to open the synchronized audience display in a separate window.
